What it checks

Five checks, each one named in the report. The report shows seven steps in all, the mint's facts and the keysets' age alongside the five checks.

C

Check the decode

Any Cashu token, v3 or v4, decoded in your browser before anything is judged.

H

Hash the keyset

Each keyset ID is recomputed from the mint's public keys. A mismatch means the keyset is not what it claims.

E

Expose collisions

A V1 keyset ID reduces to a 31-bit residue. Two mints can land on the same one, and that is the attack.

C

Confirm signatures

The signatures match the advertised key, and nothing more. DLEQ never proves the mint is honest.

K

Know the state

Only when you ask. The mint says spent, pending, or unspent. Its word, one moment, and it learns what you hold.

For wallet developers

Put the checker in your wallet

The same checks as this page, as a library. One call takes a token string and returns a report: decode, residue screen, keyset derivation, DLEQ, and the verdict. It never spends, signs, or holds proofs.

@nutcheck/core 0.1.0 on npm → 
npm install @nutcheck/core
import { diagnoseToken } from '@nutcheck/core';

const report = await diagnoseToken(token);
if (report.headline === 'Reject, here is why.') {
  // do not accept the token
}

Questions, answered

The short version of what the tool does and does not do.

A Cashu token diagnostics tool. Paste a token and it tells you what can be verified: the decode, the V1 residue screen, the keyset ID derivation, the DLEQ signatures, and, only if you ask, the proof state from the mint.

A V1 keyset ID reduces to a 31-bit residue. Two different keysets can land on the same residue. A mint with a colliding keyset can recover the secrets of the other mint's proofs, so NutCheck screens for it.

No. It never spends, signs, derives, or holds proofs. It only reads the token and, with your consent, asks the mint about proof state.

Asking a mint whether proofs are spent sends it identifiers derived from your proof secrets, so the mint learns which proofs you hold. The answer is also only the mint's own word at one moment. It stays off until you turn it on.

That the mint is honest, that it is solvent, that the proofs stay unspent after the check, or that no collision exists outside the keyset lists you supplied. The report says all of this plainly.
